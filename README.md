# Random Dice Roller

A simple and interactive web-based dice roller that generates a random dice number every time you roll the dice.

## Features

* Generates a random number from **1 to 6**
* Simple button-based interaction
* Clean and responsive interface
* Built using only HTML, CSS, and JavaScript

## Technologies Used

* **HTML** — Structure of the webpage
* **CSS** — Styling and layout
* **JavaScript** — Random dice number generation and interaction

## How to Run

1. Clone the repository:

```bash
git clone  https://github.com/jayesh-gupta-15/Dice_Roller.git
```

2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click the **Roll Dice** button to generate a random number.
